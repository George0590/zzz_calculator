# 本地数据工具

## 扫描翻页

游戏 3.3 起点击背包最下面一行不再翻页。Scanner 1.0.49 默认的“点击底行”翻页会读到重复行，由重复保护以 `duplicate_guard` 停止。

计算器的扫描请求默认带 `rowAdvanceMode: "wheel"`，使用 Scanner 自带的滚轮翻页并逐次核对位移。调用方显式提供 `rowAdvanceMode` 时仍保留该设置。

历史用户反馈在 1920×1080 下成功扫描 512 件；这不是本次分支的真实游戏验收，也不代表已覆盖所有分辨率。

核对日期：2026-10-19。本文只说明本地数据读取保护；源码实现和隔离测试不代表日常服务已更新。

## 本地解析保护

库存 localStorage fallback、计算配置和优化设置读取区分“键不存在”和“JSON 解析失败”。
只有不存在时使用默认值；解析失败抛错、保留原字符串并阻止相关保存。
页面提供“导出原始内容”，启动失败时也可先导出原始内容再处理恢复。
该保护不意味着用户现有数据损坏，也不负责自动猜测、修补损坏内容。
